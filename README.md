# Habit Tracking System

A web-based habit tracking application built with **Python and Streamlit**. The application helps users create habits, record their progress, monitor completion rates and streaks, and receive personalized motivation and habit coaching.

## Features

- Add and manage habits with frequency, target, category, and start date
- Log habit completions with timestamps
- View completion statistics and habit streaks
- Edit and remove existing habits
- Visualize habit progress
- Receive motivational quotes dynamically using the **ZenQuotes API**
- Get reminder notifications
- Receive personalized habit advice, burnout insights, and habit-stacking suggestions using an **LLM API through OpenRouter**
- Store habit and completion data using CSV files

## Technologies Used

- Python
- Streamlit
- Pandas
- OpenRouter LLM API
- ZenQuotes API
- Python-dotenv

## How It Works

1. Create a habit and define its frequency and target.
2. Log each time you complete the habit.
3. Track your completion rate and streaks.
4. View and edit your saved habits.
5. Use the Personal Habit Coach to analyze your habit history and receive personalized suggestions.
